🔑 Key Architectural Insights
  • Contract-First: Strategist defines hookPhrase, vocabulary, objectives BEFORE any generation happens
  • Bound Outputs: Each agent's output schema references strategyId — enforcing traceability
  • Parallel Safe: Context, Sticks, Curiosity, Flow have NO dependencies on each other — only on Strategy
  • Reflection Pattern: Critic doesn't generate — it validates against the original contract
  • Retry with Context: Failed attempts pass feedbackForRetry to next attempt — not blind retry
  • No Silent Fallbacks: If validation fails after 3 attempts, pipeline FAILS explicitly
